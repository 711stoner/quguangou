# 取关狗｜唯一工作目录

**只维护此文件夹，不要在桌面创建 `取关狗-v0.x`、`取关狗-测试版` 等新目录。**

- 当前插件版本：**v0.2.75**，包含 11 个商店语言／地区配置：简体中文 zh_CN、繁体中文 zh_TW 与 zh_HK，以及英语、日语、韩语、法语、西班牙语、马来语、越南语、印尼语。其中 zh_TW 和 zh_HK 共用繁体中文界面，故插件实际提供 10 个可选择的界面语言（中文简体、中文繁体及另外八种语言）。
- 插件源码：此文件夹的 `background.js`、`popup.js`、`lib/`、`l10n/` 等。
- 唯一打包入口：`python3 scripts/build.py`，也可以双击 `更新安装包.command`。
- 多语言 SEO 的唯一原稿：`商店SEO文案.json`；修改后运行打包命令会同步 11 个 `_locales` 配置并生成 `商店SEO上架文案.md`，也会同步移动硬盘里的上架文案。**完整介绍与 Edge 搜索词仍需手动填入商店后台**。
- 本地固定安装包：`dist/quguangou-chrome.zip`、`dist/quguangou-edge.zip`、`dist/quguangou-firefox.zip`。**每次构建会覆盖同名文件，不产生新版本文件名。**
- 如果外置硬盘连接，同步覆盖 `04-发布包/取关狗/` 里的三个同名安装包。
- 需要上架时按浏览器选择对应 ZIP；ZIP 文件名不含版本号，**内部 `manifest.json` 的版本号依然要在正式更新时按商店规则递增**。
- 修改代码时只修改这里的最新源码。GitHub 对应 `711stoner/quguangou` 仓库的 `fix/stalled-window-ui-v0.2.74` 分支；提交前将改动同步回仓库，不在桌面另建版本目录。
- **切勿卸载正在扫描的取关狗插件或清空 Chrome 扩展存储**。重新加载或更换本地扩展路径，可能影响 Chrome 中已保存的扫描断点；请先确认备份与扩展身份。

历史源码已保存在外置硬盘和 GitHub；桌面只保留本目录。

- 唯一 npm 构建入口：`npm run build` 和 `build:chrome` / `build:edge` / `build:firefox` 都调用 `scripts/build.py`，不会再运行旧 v0.2.25 构建逻辑；`package.json` 版本与 manifest 保持一致。


## 2026-11-04 正式上传前最后核查与剩余风险

本轮仅修改本地唯一源码、回归测试和三个固定 ZIP，**没有进入浏览器商店上传或提交审核**。此检查不操作用户真实 X 账号，不调用取关/拉黑接口。

**发现并修复的上传前风险：**

- **防止错打旧包**：旧 `npm run build` 用 v0.2.25 浏览器 manifest、创建版本号 ZIP、漏掉最新 10 种语言运行文件；旧 `scripts/build-v0.2.72.py` 也生成过期包。现已改为所有 npm 打包命令只转发到当前 `scripts/build.py`，删除弃用的旧版本构建器与旧 Edge/Firefox manifest。`package.json` 和 `manifest.json` 都为 `0.2.75`，只有 `quguangou-chrome.zip`、`quguangou-edge.zip`、`quguangou-firefox.zip` 三个包。
- **安全校验完整**：不再使用不兼容当前 ES module 后台的旧 vm.Script 假模拟，改用当前代码的批次上限、白名单、失败暂停、扫描窗口身份校验、订阅弹窗退回等安全回归检查。实际批量处理节奏最低间隔从 13 秒提高到 16 秒，20 次进入 30 分钟冷却；并新增动态时间范围测试。静态安全断言**不等于**在真实 X 实际拉黑/取关验证完成。
- **页面网络钩子隐私**：旧合成 GraphQL 分页请求已经长期禁用，但曾在内存中留有旧的请求头拷贝及可调用的分页重放接口。现不再复制任何认证头/CSRF/Cookie，请求重放接口固定返回 `SYNTHETIC_CURSOR_DISABLED`；保留 X 自己的分页响应观察和 429 状态。新增独立 VM 测试检查模拟 X 请求只发起一次、原请求头仍正常传给 X、扩展状态中不包含认证值。
- **隐私说明一致性**：十种 UI 语言的隐私说明均更新为 2026-11-04，并新增自动校验；三端权限仍限 `storage`/`scripting`/`alarms`，Chromium 另有 `sidePanel`，没有 `cookies`、`webRequest`、`debugger` 或 `<all_urls>`。
- **受支持语言和商品 SEO**：Chrome/Edge 使用 10 个官方可识别的 `_locales`（中文繁体 `zh_TW`，不发独立 `zh_HK`）；Firefox 保留既有 11 份资源。全部扩展名称限制在 45 字符内，摘要不超过 132 字符。商店详情介绍与图片需要用户自己在开发者后台按语言审核上传，源码里已有不等于线上生效。

**真实服务读取检查（只 GET，不提交任何账号）**：中文候选名单 API 以及英文、日语、韩语、法语、西班牙语、马来语、越南语、印尼语的独立候选 API 全部正常响应、分区正确，但本次抽样 `limit=1` 查询全部返回 0 个候选。由于其他语言没有审核数据，可能显示空社区名单，**不能用中文账号名单填充这些语言**。这是内容覆盖范围，不是插件接口故障。

**上传后仍须验收**：在真实 X 的大规模账号上完成完整 Following/Followers 扫描（特别是 429、几千人关系表），并在明确授权的测试账号上验证批量操作；本轮仅模拟隔离浏览器状态，无法保证 X 从此不触发限制。历史商店截图的画面文字仍需与目前 UI 逐张核对；目前公开 Chrome 商店仍为 v0.2.63，仅中文与英文 Listing 有效，另外八个目标语言仍待用户后台上传新版及对应截图/详细介绍。
