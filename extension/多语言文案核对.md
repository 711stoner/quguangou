# 取关狗｜多语言文案核对记录

更新日期：2026-11-03；当前扩展版本 v0.2.74。统一维护目录：`桌面/取关狗/`。

## 核对范围

- 商店语言／地区配置：**11 个**（zh_CN、zh_TW、zh_HK、en、ja、ko、fr、es、ms、vi、id）。`zh_TW` 和 `zh_HK` 共用繁体中文翻译，界面提供 **10 种可选语言**。
- 以简体中文功能定义为基准，核对所有语言的首页、两种模式、关注检测、操作按钮、错误反馈、暂停/恢复窗口、429 限流提示、白名单、社区名单、隐私页面以及浏览器商店的短标题/简介。
- 审查静态 HTML、浏览器商店 `_locales/*/messages.json`、动态翻译词典和浏览器中的实际运行结果。

## 发现并修复

1. **繁体中文：** 清理“讀取消追蹤注你的人”误写，统一为“讀取追蹤你的人”；纠正“頁面過載”对“页面重载”的错误理解，改为“頁面重新載入”；隐私页面“許可權”“發帖內容”调整为更自然的“權限”“貼文內容”，并统一异常提示用词。
2. **英文和繁体中文：** 补齐之前只在简体中文实现的扫描窗口消失、几分钟无进度的动态检测/提示；不再让固定文案覆盖实际运行中的状态说明。
3. **日、韩、法、西、马来、越、印尼文：** 修复扫描进度中未替换的 `Followers` / `Following`，补齐“扫描停滞”的动态翻译，消除旧版“正在快速读取”不准确的暗示。调整拼接片段中丢失空格的问题，包括马来语、越南语、印尼语的数字和单位。
4. **西班牙语：** 修正 `Fase ... terminado` 的性别搭配，使用 `completada`。
5. **印尼语、马来语、越南语：** 清理重复引用的语言切换样式表。
6. **十语言按钮：** 统一英文、繁体中文及部分语言的窗口重开按钮与帮助文案用词，减少“强制重开”造成的误解。

## 验收

- 静态检查：11 个地区翻译包完整；10 种界面的 85 个 HTML 控件 ID 全部一致；各隐私页面主要章节数量一致；非中文界面（日本语除外）的 HTML 不包含汉字残留。
- 动态检查：Chromium 隔离测试档案模拟了 **扫描窗口消失／进度停滞、用户手动暂停、X HTTP 429 冷却**，逐一检查 10 种界面语言显示、按钮和主要进度信息；未发现页面脚本错误。
- 自动化：`node --test test/locale-copy.test.mjs test/scan-stall-help.test.mjs test/scan-pacing.test.mjs` 通过 18 项测试。
- Chrome、Edge、Firefox 发行包仍使用 `quguangou-chrome.zip`、`quguangou-edge.zip`、`quguangou-firefox.zip` 固定名称覆盖，不另起版本。

## 边界

- 这些是本地的文本、规则及模拟浏览器验收，不是有偿的母语译者逐句认证。部分罕见的 X 服务器错误文本仍由安全的本地化通用错误提示兜底，不能保证 X 未来新增的报错文案永不变更。
- 商店图片（已存储的多个版本）并未在本轮重新渲染/逐张审阅图片文字；商店图片的语言和截图版本应在上架前单独复核。
- 尚未将新安装包提交浏览器商店；不要卸载正在使用的插件或清空浏览器中扫描断点数据。
