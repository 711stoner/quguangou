최종 업데이트: 2026년 10월 3일

처리하는 정보

이 확장 프로그램은 커뮤니티 차단 목록과 내 계정 모드를 제공합니다. 커뮤니티 모드에서는 선택한 X 계정의 공개 프로필을 방문해 작업 버튼을 확인하고 차단 결과를 검사합니다. 내 계정 모드에서는 로그인한 계정의 프로필, 팔로잉 및 팔로워 목록을 읽어 현재 맞팔로우 여부를 확인합니다.

과거 언팔로우 기록이나 최근에 나를 언팔한 사람은 추적하지 않습니다. X 비밀번호, 인증 쿠키, 비공개 메시지, 게시물 본문을 수집하거나 저장하지 않습니다.

기기 내 저장

작업 진행 상황, 대상 계정, 처리 결과, 검사 상태, 목록 페이지의 이어받기 위치, 마지막 화면을 브라우저에 저장해 중단된 작업을 재개할 수 있게 합니다. 이어받기 위치는 목록 읽기 재개 용도로만 사용합니다. 인증·쿠키·CSRF 요청 헤더는 저장하지 않습니다. 검사 중에는 팔로잉과 팔로워 목록을 일시 저장하지만 완료 후 전체 목록을 삭제하고, 계정 이름·통계·맞팔하지 않는 후보 등 결과에 필요한 정보만 유지합니다. 확장 프로그램 삭제 또는 데이터 초기화로 제거할 수 있습니다.

보호 목록은 현재 브라우저 프로필의 이 확장 프로그램에만 저장됩니다. 다른 Chrome 프로필이나 별도로 설치한 확장 프로그램에는 자동으로 옮겨지지 않습니다. 기본 기록이 사라졌을 때 복구할 수 있도록 같은 확장 프로그램에 별도 백업을 저장하지만, 확장 프로그램을 삭제하거나 데이터를 지우면 보호 목록이 사라질 수 있습니다.

데이터 전송 및 커뮤니티 공유

공유 차단 목록은 확장 프로그램 기본 데이터와 관리자가 검토한 사용자 제출 항목으로 구성됩니다. 대기 시간 등에 공유를 제안할 수 있지만, 사용자가 명시적으로 ‘모두 제출’을 선택할 때만 이번 작업에서 차단 또는 언팔로우에 성공한 대상 X 사용자 이름을 제출합니다. 중복 방지를 위한 익명 난수 식별자가 함께 전송되며, 내 X 계정과 관련이 없고 로그인에 사용할 수도 없습니다. 공개 목록에 반영되기 전에 관리자가 검토합니다.

내 X 사용자 이름, 비밀번호, 쿠키, 비공개 메시지, 게시물 본문 또는 동의하지 않은 결과는 전송하지 않습니다.

권한 사용 목적

  • storage: 작업 진행 상황, 검사 상태 및 결과를 기기에 저장
  • alarms: 브라우저 일시 중단 후 검사를 재개하도록 주기적으로 확장 프로그램 실행
  • sidePanel: X를 탐색하는 동안 사이드 패널 유지
  • scripting: X 페이지 상태 확인 및 동의 후 차단·언팔로우 조작
  • https://x.com/*: 현재 계정의 프로필과 선택한 대상 프로필에 접근
  • https://quguangou-community-api.juejiangfm.workers.dev/*: 커뮤니티 목록을 불러오고 동의한 처리 결과 제출
  • https://quguangou-locale-community.juejiangfm.workers.dev/*: 언어별 커뮤니티 검토 목록을 조회하고 제출합니다.

커뮤니티 목록은 화면 언어별로 구분됩니다. 중국어 간체와 번체만 중국어 목록을 공유하고, 나머지 언어는 각각 독립적입니다. 제출 내용은 검토된 뒤 해당 언어 목록에만 표시됩니다.

사용자가 직접 결정합니다

사용자 동의 없이 검사, 차단, 언팔로우 또는 커뮤니티 제출을 시작하지 않습니다. 검사는 시작 버튼을 누른 뒤 실행되며, 결과 확인과 계정 선택, 별도 확인 후 일정 간격으로 처리합니다. 커뮤니티 공유도 명시적인 선택이 필요합니다.
