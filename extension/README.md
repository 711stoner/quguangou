# 取关狗

一个本地加载的 Chrome Manifest V3 扩展。用户登录自己的 X 账号后，可以一键拉黑扩展内置名单里的账号。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹 `quguangou-chrome`。
5. 先在 Chrome 中登录 `x.com`，再点击工具栏里的“取关狗”。

## 内置名单

名单保存在 `data/blocklist.json`。发布者可以加入 X 用户链接、`@用户名`、裸用户名或数字用户 ID，例如：

```json
{
  "version": "2026-09-09",
  "updated_at": "2026-09-09",
  "description": "需要拉黑的账号名单",
  "accounts": [
    "https://x.com/example_account",
    "@another_account",
    "123456789"
  ]
}
```

更新名单后，需要发布扩展新版本，或者在 `chrome://extensions` 中重新加载扩展。普通用户界面不提供编辑名单的入口。

## 使用

打开扩展即可查看内置名单。点击“一键拉黑全部账号”后，扩展会创建一个非活动标签页，并依次进入每个账号主页完成拉黑。

任务结果保存在 `chrome.storage.local`，关闭扩展弹窗不会清空进度。点击“停止任务”可取消尚未处理的账号。

## 注意

- 建议先用 1–2 个测试账号确认当前 X 页面可以正常识别。
- 扩展依赖 X 网页的按钮和菜单结构；X 改版后可能需要更新选择器。
- 扩展不会读取或保存 X 密码，也不会把账号清单发送给第三方服务。
- 请控制批量规模和使用频率，并遵守 X 的适用条款。
