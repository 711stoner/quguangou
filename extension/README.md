# 取关狗

取关狗浏览器扩展源码，支持为 Chrome、Edge、Firefox 和 Opera 构建对应版本。包含「私人账号」和「社区名单」两种独立模式：私人账号可比对当前 X 账号的关注／粉丝关系，找出没有回关你的账号；社区名单模式可查看经审核的共享名单，并在明确确认后分批拉黑。**它不追踪谁最近取关你，也不提供历史取关记录。**

**截至 2026-09-26，取关狗社区名单当前有效收录 138 个账号。**

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `extension` 文件夹。
5. 先在 Chrome 中登录 `x.com`，再点击工具栏里的“取关狗”。

## 在线名单与本地备用

名单唯一源文件保存在 `data/blocklist.json`。发布后，GitHub Pages 会把它提供为在线名单：`https://711stoner.github.io/quguangou/extension/data/blocklist.json`。插件打开时优先读取在线名单；如果在线请求失败，会先使用上一次成功缓存，再回退到随扩展打包的本地备用名单。发布者可以加入 X 用户链接、`@用户名`、裸用户名或数字用户 ID，例如：

```json
{
  "version": "2026-09-09",
  "updated_at": "2026-09-09",
  "description": "需要拉黑的账号名单",
  "accounts": [
    "https://x.com/example_account",
    "@another_account",
    "123456789"
  ]
}
```

从 v0.2.14 开始，只更新名单不需要重新发布扩展。修改 `data/blocklist.json` 并推送到 GitHub 后，等 GitHub Pages 部署完成，已安装插件的用户再次打开插件即可读取最新名单。只有插件代码、权限、界面或运行逻辑发生变化时才需要提交 Firefox / Edge / Chrome / Opera 新版本。普通用户界面不提供编辑名单的入口。

## 使用

打开扩展即可查看社区名单。该名单不是根据当前用户的粉丝或关注关系生成的。点击“开始处理第 1 批”后，扩展会创建一个非活动标签页，并按分批节奏依次处理账号：每批最多 20 个，一批结束后强制冷却 30 分钟；冷却结束后，下一批必须由用户再次手动点击继续。例如 100 个账号需要分 5 批、手动操作 5 次。账号之间仍保留操作间隔。

任务结果保存在 `chrome.storage.local`，关闭扩展弹窗不会清空进度。点击“停止任务”可取消尚未处理的账号。冷却期间可通过次级入口主动跳过，但必须先确认风险；默认建议等待完整 30 分钟。跳过冷却会提高连续自动操作频率，可能增加触发 X 频率限制、验证、账号功能受限或暂停等风控的概率。名单会持续更新，用户可以之后再回来查看新增名单并继续分批处理。每批进入拟人化冷却时会提供一张可选的 X 推文广告价值估算入口；全部处理完成后也会提供一张完成场景入口。首页不显示估值入口，同一状态不会重复显示两张；不会强制跳转。

## 注意

- 建议先用 1–2 个测试账号确认当前 X 页面可以正常识别。
- 扩展依赖 X 网页的按钮和菜单结构；X 改版后可能需要更新选择器。
- 扩展不会读取或保存 X 密码。社区名单会从在线源读取；私人账号检测进度与白名单默认保存在当前浏览器。只有用户主动确认提交社区名单时，符合条件的处理结果才会按隐私说明进入审核流程，不会在用户未确认的情况下自动公开。
- 请控制批量规模和使用频率，并遵守 X 的适用条款。


## 扫描末尾与受限账号处理

扫描接近列表末尾但人数尚有差额时，会提示核对最后一段；不会虚构缺失账号。如果完成后 X 主页总数仍高于实际可读取人数，结果会提示可能误判。私人账号的已确认取关任务遇到 X 受限账号提示时，只针对明确的“同意／查看主页”按钮尝试点击一次，随后重新核对登录账号、目标、白名单和关注状态。不点击一般法律/付费/订阅授权，不把同意当成取关成功。
