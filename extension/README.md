# 取关狗

取关狗浏览器扩展源码，支持为 Chrome、Edge 和 Firefox 构建对应版本。它不是取关检测器；用户登录自己的 X 账号后，可以查看人工整理的 X 中文社区名单，并在确认后一键依次拉黑名单里的账号。

**截至 2026-09-13，取关狗社区名单已收录 64 个账号。**

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `extension` 文件夹。
5. 先在 Chrome 中登录 `x.com`，再点击工具栏里的“取关狗”。

## 在线名单与本地备用

名单唯一源文件保存在 `data/blocklist.json`。发布后，GitHub Pages 会把它提供为在线名单：`https://711stoner.github.io/quguangou/extension/data/blocklist.json`。插件打开时优先读取在线名单；如果在线请求失败，会先使用上一次成功缓存，再回退到随扩展打包的本地备用名单。发布者可以加入 X 用户链接、`@用户名`、裸用户名或数字用户 ID，例如：

```json
{
  "version": "2026-09-09",
  "updated_at": "2026-09-09",
  "description": "需要拉黑的账号名单",
  "accounts": [
    "https://x.com/example_account",
    "@another_account",
    "123456789"
  ]
}
```

从 v0.2.14 开始，只更新名单不需要重新发布扩展。修改 `data/blocklist.json` 并推送到 GitHub 后，等 GitHub Pages 部署完成，已安装插件的用户再次打开插件即可读取最新名单。只有插件代码、权限或界面发生变化时才需要提交 Firefox / Edge / Chrome 新版本。普通用户界面不提供编辑名单的入口。

## 使用

打开扩展即可查看社区名单。该名单不是根据当前用户的粉丝或关注关系生成的。点击“一键拉黑全部账号”后，扩展会创建一个非活动标签页，并依次进入每个账号主页完成拉黑。

任务结果保存在 `chrome.storage.local`，关闭扩展弹窗不会清空进度。点击“停止任务”可取消尚未处理的账号。

## 注意

- 建议先用 1–2 个测试账号确认当前 X 页面可以正常识别。
- 扩展依赖 X 网页的按钮和菜单结构；X 改版后可能需要更新选择器。
- 扩展不会读取或保存 X 密码；只会从 GitHub Pages 下载公开社区名单，不会上传用户的 X 账号数据或任务记录。
- 请控制批量规模和使用频率，并遵守 X 的适用条款。
