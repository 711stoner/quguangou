## 问题原理和可验证结论

截图中 Chrome 商店导航栏为英文，中文关键词「取关狗」返回英文标题；Google 搜索结果则保留了中文标题。这两个系统各自决定结果显示语言，Google 索引会缓存不同语言标题，不代表 Chrome 商店的搜索词决定展示语言。

实际通过独立 Chromium 访问同一个商店插件 URL 并改变 `?hl=`：`取关狗 + hl=en` 结果为英文；`取关狗 + hl=zh-CN` 结果为中文。反过来用英文关键词 `Followback Watchdog`，中文商店语言仍给出中文标题，英文商店语言仍给英文。**搜索关键词不控制 Listing 的展示语言。这不是本地插件代码可修改的逻辑，也不能承诺 100% 按查询文字匹配。**

Chrome 官方说明：通过 `_locales/<locale>/messages.json` 本地化扩展标题和简短描述；但完整介绍和本地化截图必须在 Developer Dashboard 的 Store listing 中，按语言分别编辑并提交。已上传到本地仓库或电脑的 ZIP 不会自动更新线上内容。
