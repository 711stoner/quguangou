# 审核人员测试说明

取关狗的单一用途是：向用户展示由发布者预置的 X 中文社区取关名单，并在用户明确点击后依次拉黑名单中的 X 账号。它不是取关检测器，不扫描用户自己的粉丝/关注历史，也不会根据当前账号关系自动生成名单。

测试步骤：

1. 使用 Chrome 登录一个可用于测试的 X 账号。
2. 点击工具栏中的“取关狗”。
3. 确认弹窗显示社区名单版本和账号清单。扩展会优先从 `https://711stoner.github.io/quguangou/extension/data/blocklist.json` 读取最新公开名单；请求失败时回退到上次缓存或随扩展打包的本地备用名单。
4. 点击“一键拉黑全部账号”。
5. 扩展会创建一个非活动标签页，依次访问名单中的账号。
6. 在弹窗中检查进度，以及“已拉黑”“已拉黑过”或“失败”结果。
7. 可点击“停止任务”验证取消功能。

扩展不会在安装时或浏览网页时自动执行。所有可执行逻辑都随 ZIP 提交，没有远程代码。远程资源仅为静态 JSON 数据（版本、更新时间、说明和账号字符串列表），不会被 `eval`、动态导入或作为脚本执行。`https://711stoner.github.io/*` 权限只用于 GET 这份公开名单。任务状态只保存在 `chrome.storage.local`；扩展不会把用户的 X 账号信息、粉丝/关注历史、任务记录或拉黑结果上传给开发者，也没有分析 SDK 或广告 SDK。

提交前需要将一至两个由开发者控制、允许审核人员拉黑的测试账号加入内置名单。不要要求审核人员拉黑无关第三方账号。
