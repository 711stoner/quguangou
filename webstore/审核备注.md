# 审核人员测试说明

取关狗的单一核心用途是：展示由社区公开线索、用户提交材料和人工复核形成的 X 中文社区黑名单 / 单向取关线索，并在用户明确点击后，以分批方式拉黑名单中的 X 账号。

它不是个人取关检测器，不扫描用户自己的粉丝 / 关注历史。

测试步骤：
1. 登录一个可用于测试的 X 账号
2. 打开取关狗，确认社区名单版本和账号清单
3. 在线名单优先从 https://711stoner.github.io/quguangou/extension/data/blocklist.json 读取，失败时回退缓存或内置备用名单
4. 点击“开始处理第 1 批（最多 20 个）”
5. 单个账号如被 X 停用、已注销、404 或无法访问，记录原因后继续
6. 每批最多处理 20 个，结束后进入 30 分钟拟人化冷却，冷却结束后用户手动继续
7. 冷却期间只显示一张可选 X 推文广告价值估算入口
8. 全部处理完成后只显示一张完成场景入口
9. 两个入口都不会自动打开外部页面，也不影响核心功能

所有可执行 JavaScript 都随 ZIP 提交，没有远程代码。远程资源仅为静态 JSON 名单数据。
https://711stoner.github.io/* 权限只用于 GET 公开名单。
任务状态仅保存在 chrome.storage.local；不会把 X 账号信息、粉丝 / 关注历史、任务记录或拉黑结果上传给开发者。
估值入口只在用户主动点击后打开开发者自有网站，不会自动传送 X 账号数据或任务结果。
