我们处理哪些信息

扩展仅在用户主动点击“一键拉黑全部账号”后访问 x.com 用户页面，以识别用户操作菜单、执行拉黑并判断操作结果。扩展不会读取、请求或保存用户的 X 密码、身份验证 Cookie、私信或发帖内容。

本地存储

扩展使用 Chrome 本地存储保存当前任务进度、目标账号和执行结果。这些信息只保存在用户设备中，可以通过卸载扩展或清除扩展数据删除。

数据传输与共享

扩展没有开发者服务器、分析工具或广告组件，不会把用户数据、浏览活动、任务记录或 X 账号信息发送给开发者或第三方。与 X 的页面访问由用户自己的浏览器直接完成。

权限用途

  • storage：在本地保存任务进度和结果。
  • scripting：在 X 用户页识别并点击拉黑相关控件。
  • https://x.com/*：打开内置名单中的 X 用户页并完成用户主动发起的操作。

用户控制

扩展不会自动启动。用户可以在执行前查看名单，必须主动点击按钮才能开始，并可以随时停止尚未完成的任务。

有限使用承诺

取关狗对通过浏览器权限获得的信息的使用，将遵守 Chrome Web Store 用户数据政策（包括有限使用要求），并仅限于提供本政策所述的单一功能。

联系我们

如对本隐私政策或扩展的数据处理方式有疑问，请通过官网后续公布的 X 评论链接或 X 群聊入口联系。
