# Chrome Web Store 上架文案

## 名称

取关狗

## 摘要

查看扩展内置的 X 账号名单，并在用户主动确认后依次完成拉黑操作。

## 详细说明

新人账号进行冷启动时，互相关注是一种常见的连接方式。当账号在获得关注后单方面取消关注且不作说明，会增加关系维护成本并损害互关信任。取关狗帮助用户在自己的 X 账号中查看和处理这类记录形成的内置名单。

名单线索来自用户提交，并要求提供相关截图证据。线索经过整理和复核后才会随扩展版本加入名单。收录不代表对账号作违法或恶意定性；被收录账号可以通过公开留言或联系邮箱说明情况，名单维护者会根据反馈和补充证据进行复核、更正或移除。

安装后，用户可以先查看当前名单、名单版本和账号数量。只有用户主动点击“一键拉黑全部账号”后，扩展才会打开一个非活动标签页，依次进入名单中的 X 用户主页并执行拉黑。执行期间会展示进度，并分别标记已拉黑、已拉黑过和失败的账号；用户可以随时停止尚未完成的任务。

主要功能：

- 查看扩展内置的完整账号名单和版本
- 一次点击后按顺序执行，任务不会在后台自动启动
- 自动跳过已经拉黑的账号
- 显示实时进度与逐项结果
- 随时停止尚未完成的任务
- 所有任务数据仅保存在用户自己的设备中

使用要求：

- 用户需要先在 Chrome 中登录自己的 X 账号
- 扩展仅访问 x.com，不读取或保存 X 密码
- 名单随扩展版本发布，普通用户无法自行添加账号

取关狗不是 X Corp. 的官方产品，也未获得 X Corp. 的认可或授权。扩展依赖 X 网页界面完成操作；如果 X 更新页面结构，部分功能可能暂时需要适配。
