# Chrome Web Store 上架文案

## 名称

取关狗 - X/Twitter 取关名单与一键拉黑

## 摘要

不是取关检测器。整理 X 中文社区公开曝光、互关帖异常关注比例线索和用户投稿形成的取关名单，用户确认后可一键依次拉黑。

## 详细说明

取关狗不是“谁取关了你”的取关检测工具。它不会扫描用户的关注列表、粉丝历史，也不会告诉用户“刚刚谁取消关注了你”。它做的是整理整个 X 中文社区中已经公开出现、或由社区用户提交的互关后取关线索。

名单线索主要来自三类来源：

1. X 中文社区公开帖子中对“互关后取关”的曝光记录；
2. 在互关帖下主动留言、但主页关注与粉丝比例明显异常的账号线索，例如关注约 1000 人、粉丝约 3000 人。此类比例只作为待核对线索，不单独认定取关行为；
3. 用户私信或公开投稿的“互关后又取关我”记录，并附截图、时间线等材料。

线索经过人工整理和复核后才会随扩展版本进入名单。名单来自整个 X 中文社区，并不只包含用户自己当前关注的人。收录不代表对账号作违法或恶意定性；被收录账号可以补充说明，名单维护者会根据反馈和材料进行复核、更正或移除。

安装后，用户可以先查看当前名单、名单版本和账号数量。只有用户主动点击“一键拉黑全部账号”后，扩展才会打开一个非活动标签页，依次进入名单中的 X 用户主页并执行拉黑。执行期间会展示进度，并分别标记已拉黑、已拉黑过和失败的账号；用户可以随时停止尚未完成的任务。

主要功能：

- 查看扩展内置的完整账号名单和版本
- 一次点击后按顺序执行，任务不会在后台自动启动
- 自动跳过已经拉黑的账号
- 显示实时进度与逐项结果
- 随时停止尚未完成的任务
- 所有任务数据仅保存在用户自己的设备中

使用要求：

- 用户需要先在 Chrome 中登录自己的 X 账号
- 扩展仅访问 x.com，不读取或保存 X 密码
- 名单随扩展版本发布，普通用户无法自行添加账号

取关狗不是 X Corp. 的官方产品，也未获得 X Corp. 的认可或授权。扩展依赖 X 网页界面完成操作；如果 X 更新页面结构，部分功能可能暂时需要适配。
