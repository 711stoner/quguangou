# Chrome Web Store 上架文案

## 名称

取关狗｜X/Twitter 取关名单与批量拉黑

## 摘要

X/Twitter 取关与互关管理工具：查看社区提交的单方面取关名单，核对账号后可批量拉黑，帮助中文用户管理关注关系。

## 详细说明

取关狗是一款面向 X（Twitter）中文用户的取关名单与互关管理 Chrome 扩展。它整理社区公开曝光、互关帖线索和用户投稿形成的单方面取关记录，方便用户查看名单、核对账号，并在主动确认后批量执行拉黑。

它不是“谁刚刚取关了你”的自动取关检测器，不会扫描用户的关注列表或粉丝历史，也不会自动判断某个账号是否刚刚取消关注。

**截至 2026-09-13，取关狗社区名单已收录 64 个账号。**

名单线索主要来自三类来源：

1. X 中文社区公开帖子中对“互关后取关”的曝光记录；
2. 在互关帖中明确表示“互关、交友”的账号，如果主页关注与粉丝比例明显异常，例如关注约 1000 人、粉丝约 3000 人，会作为重点核对线索；
3. 用户私信或公开投稿的“互关后又取关我”记录，并附截图、时间线等材料。

线索经过人工整理和复核后进入在线社区名单。名单来自整个 X 中文社区，并不只包含用户自己当前关注的人。收录不代表对账号作违法或恶意定性；被收录账号可以补充说明，名单维护者会根据反馈和材料进行复核、更正或移除。

安装后，用户可以先查看当前名单、名单版本和账号数量。只有用户主动点击“一键拉黑全部账号”后，扩展才会打开一个非活动标签页，依次进入名单中的 X 用户主页并执行拉黑。执行期间会展示进度，并分别标记已拉黑、已拉黑过和失败的账号；用户可以随时停止尚未完成的任务。

主要功能：

- 查看在线社区名单、名单版本、更新时间和账号数量
- 一次点击后按顺序执行，任务不会在后台自动启动
- 自动跳过已经拉黑的账号
- 显示实时进度与逐项结果
- 随时停止尚未完成的任务
- 所有任务数据仅保存在用户自己的设备中

使用要求：

- 用户需要先在 Chrome 中登录自己的 X 账号
- 扩展仅访问 x.com，不读取或保存 X 密码
- 插件会读取项目公开维护的最新社区名单；在线读取失败时使用缓存或本地备用名单

取关狗不是 X Corp. 的官方产品，也未获得 X Corp. 的认可或授权。扩展依赖 X 网页界面完成操作；如果 X 更新页面结构，部分功能可能暂时需要适配。
