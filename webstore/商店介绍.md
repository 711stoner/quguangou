# Chrome Web Store 上架文案

## 名称
取关狗｜X/Twitter 黑名单、单向取关与分批拉黑

## 摘要
X/Twitter 中文社区黑名单与单向取关线索工具：查看社区名单，核对账号后分批拉黑，并采用拟人化冷却。

## 详细说明
取关狗是一款面向 X（Twitter）中文用户的账号管理辅助工具，核心用途是整理社区黑名单与单向取关线索，并帮助用户在主动确认后分批拉黑名单账号。

它不是“谁刚刚取关了你”的自动取关检测器，不会扫描用户自己的粉丝列表或关注历史，也不会自动判断某个账号是否刚刚取消关注。

截至 2026-09-26，社区名单当前有效收录 138 个账号。

主要功能：
- 查看在线社区黑名单、单向取关线索、名单版本、更新时间和账号数量；
- 用户主动点击后开始处理，每批最多处理 20 个账号；
- 账号之间保留操作间隔，每批完成后进入 30 分钟拟人化冷却；
- 冷却结束后由用户再次手动点击继续下一批；
- 自动跳过已经拉黑的账号；
- 对被 X 停用、已注销或无法访问的账号记录原因后继续处理；
- 显示实时进度与逐项结果；
- 任务状态和结果仅保存在用户自己的浏览器本地。

可选附带入口：
- 每批 20 个处理完成进入冷却时，显示一个可选的 X 推文广告价值估算入口；
- 全部名单处理完成时，再显示一个完成场景估值入口；
- 首页不显示估值入口，同一状态只显示一个；
- 点击后打开开发者自有网站的估值页面，不点击不影响黑名单、单向取关线索查看或分批拉黑。
- 估值计算不在扩展内部完成，因此统一表述为“广告价值估算入口”。

使用与隐私：
- 使用前需要在当前浏览器登录自己的 X 账号；
- 不读取、请求或保存 X 密码、身份验证 Cookie、私信或发帖内容；
- 不扫描用户自己的粉丝/关注历史；
- 不把任务记录、拉黑结果或 X 账号信息上传给开发者；
- 在线名单只是静态 JSON 数据，不作为远程代码执行。
