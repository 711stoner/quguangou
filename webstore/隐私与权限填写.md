# Chrome Web Store 隐私表填写建议

## 单一用途说明
向用户展示 X 中文社区黑名单与单向取关线索，并在用户主动确认后，以分批方式打开名单中的 X 用户主页并执行拉黑，同时在本地显示任务进度和结果。

批次冷却与全部处理完成时会提供一个可选的 X 推文广告价值估算入口。该入口不使用扩展权限读取用户数据，不影响上述核心用途。

## 权限
storage：仅用于本地保存任务目标、进度、执行结果、冷却状态与在线名单缓存。
scripting：仅在用户主动开始任务后，在 x.com 用户主页识别操作菜单、拉黑按钮和结果。
https://x.com/*：仅用于核心名单处理。
https://711stoner.github.io/*：仅用于 GET 公开静态社区名单 JSON，不包含可执行代码。

## 远程代码
选择：否，我未使用远程代码。
全部 JavaScript 均包含在扩展安装包内。远程名单只是普通 JSON 数据。

## 用户数据
扩展不收集 X 密码、身份验证 Cookie、私信或发帖内容；不扫描粉丝 / 关注历史；不把浏览数据、任务记录或页面内容发送给开发者或第三方。
估值入口只在用户主动点击后打开 jiedanfadan.com/value-check，扩展不会自动向该页面传送 X 账号信息、名单处理结果或浏览历史。
