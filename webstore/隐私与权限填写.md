# Chrome Web Store 隐私表填写建议

## 单一用途说明

在用户主动点击后，依次打开扩展内置名单中的 X 用户主页，并代表已登录用户执行拉黑操作，同时在本地显示任务进度和结果。

## 权限说明

### storage

仅用于在用户设备本地保存当前任务的目标、进度和执行结果，使用户关闭扩展弹窗后仍可查看或继续任务。数据不会传输给开发者服务器或第三方。

### scripting

仅在用户主动开始任务后，用于在 x.com 用户主页中识别用户操作菜单、拉黑按钮、确认按钮和操作结果。扩展不会在其他网站执行脚本。

### https://x.com/* 主机权限

扩展的唯一功能要求访问内置名单中的 X 用户主页并完成用户主动发起的拉黑操作，因此需要限定于 https://x.com/* 的主机权限。不访问其他网站。

## 远程代码

选择：否，我未使用远程代码。

说明：全部 JavaScript 均包含在扩展安装包内。扩展不下载、解释或执行来自远程服务器的 JavaScript 或 WebAssembly。

## 用户数据声明

建议披露“网站内容”和“网络浏览活动”，并在说明中填写：

扩展仅在用户主动执行任务期间，本地处理 x.com 用户页的页面地址、可见操作菜单和按钮状态，用于完成拉黑和显示结果。扩展不收集 X 密码、身份验证 Cookie、私信或发帖内容；不将任何浏览数据或页面内容发送给开发者或第三方，也不用于广告、分析、信用评估或任何与单一用途无关的目的。

根据后台实际选项，确认以下声明：

- 不向第三方出售用户数据
- 不将用户数据用于与扩展单一用途无关的目的
- 不将用户数据用于信用评估或贷款
- 不允许人工读取用户数据
- 数据使用符合 Chrome Web Store 用户数据政策和有限使用要求
