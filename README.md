# 取关狗

取关狗是一个面向 X 互关冷启动场景的 Chrome 扩展项目。它帮助用户查看由截图证据支持、经维护者审核的单方面取关记录，并在用户明确确认后，按顺序处理扩展内置名单。

## 目录

- 根目录：GitHub Pages 官网，包含使用方法、项目来历、名单原则、隐私政策与留言入口占位。
- `extension/`：Chrome Manifest V3 扩展源码。
- `webstore/`：Chrome Web Store 上架文案、审核备注与图片素材。

## 名单线索与反馈

- 提交名单线索：联系方式暂未开放，后续会在官网放置 X 评论链接或 X 群聊入口。提交时请附经过必要遮盖的截图证据。
- 账号纠错或申诉：联系方式暂未开放，后续会在官网统一放置 X 评论链接或 X 群聊入口。

不要提交密码、Cookie、访问令牌、手机号、个人联系方式、私信或其他无关人员信息。
