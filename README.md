# 取关狗｜X 中文社区取关名单与一键拉黑工具

取关狗不是“谁取关了你”的取关检测器。它整理 X 中文社区公开曝光、互关帖异常关注比例线索和用户投稿，经人工复核后形成社区名单；用户明确确认后，可按顺序处理名单中的账号。名单来自整个社区，不只限于用户自己当前关注的人。

把注意力，还给自己。

## 项目入口

- 官网：https://711stoner.github.io/quguangou/
- 最新下载：https://github.com/711stoner/quguangou/releases/latest
- 反馈与留言评论区：https://x.com/woyongyuangeson/status/2098974760801870134?s=20

## 它能做什么

- 查看由 X 中文社区线索整理形成的名单和名单版本。
- 用户主动确认后，逐个打开 X 主页并尝试拉黑。
- 每批最多处理 20 个账号，冷却半小时后需要用户手动继续。
- 不读取 X 密码，不上传账号数据，不依赖远程服务器完成拉黑。

## 目录

- 根目录：GitHub Pages 官网，包含使用方法、项目来历、名单原则、隐私政策与反馈留言入口。
- `extension/`：Chrome Manifest V3 扩展源码。
- `webstore/`：Chrome Web Store 上架文案、审核备注与图片素材。
- `docs/`：维护说明、版本记录和下次修改时需要看的资料。

## 名单线索与反馈

名单线索主要来自三类来源：公开帖子中对“互关后取关”的曝光记录；互关帖下留言但关注/粉丝比例明显异常的账号线索（仅作辅助判断，不单凭比例收录）；以及用户私信或公开投稿的“互关后又取关我”记录。

- 提交名单线索：请提供公开帖链接、账号、截图或时间线等可核对材料。
- 账号纠错或申诉：请说明原因并提交补充材料。

不要提交密码、Cookie、访问令牌、手机号、个人联系方式、私信或其他无关人员信息。
