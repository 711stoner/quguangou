# 取关狗 Opera 上架说明

版本：v0.2.25

## 审核重点
- One goal：核心用途统一描述为 X 中文社区黑名单、单向取关线索与用户主动分批拉黑
- 工具栏按钮直接进入名单主功能
- 权限只保留 storage、scripting、x.com 与远程名单数据源
- 所有 JavaScript 都打包在扩展内部，在线名单只是静态 JSON
- 自有网站链接必须相关且有明确作用，不让弹窗被大量推广链接占据
- 首页不显示估值入口
- 进入 30 分钟冷却时只显示一张估值入口
- 全部处理完成时只显示一张完成场景估值入口
- 不点击估值入口不影响核心功能
- 估值入口打开 https://jiedanfadan.com/value-check
