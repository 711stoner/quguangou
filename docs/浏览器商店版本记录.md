# 取关狗：浏览器商店版本记录

最后更新：2026-09-24

## 记录规则

- 只记录真实上传到 Chrome、Edge、Firefox 商店后台的版本。
- 审核中的版本也记录，但必须写清 Pending review / In review / 已通过 / 已上线等真实状态。
- 本地测试版、临时包、错误包如果没有上传商店，一律不记录。
- 单纯更新在线名单而没有重新上传扩展包，不新增插件版本记录。
- 每条至少记录：版本号、上传日期、平台、审核/上线状态、本次主要更新。
