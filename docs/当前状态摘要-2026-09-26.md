## 当前 UI 规则

- 首页：**不显示估值入口**
- 每批最多处理 20 个账号
- 每批结束后进入 30 分钟拟人化冷却
- 冷却期间：只显示 **1 张** X 推文广告价值估算入口
- 全部完成后：只显示 **1 张**完成场景估值入口
- 同一状态不重复显示多个估值入口
- 单个账号被 X 停用、已注销、404 或无法访问：记录原因并继续，不暂停整批
- 未登录、页面结构异常、脚本/操作错误等系统性问题：仍可暂停供检查

## 当前统一产品定位

正式名称：

`取关狗｜X（Twitter）黑名单、单向取关与分批拉黑`

核心用途：

> 面向 X 中文社区的账号管理辅助工具：展示社区黑名单与单向取关线索，并由用户主动发起、按分批节奏拉黑名单账号。

必须一直明确：

- 不是个人取关检测器
- 不扫描用户自己的粉丝 / 关注历史
- 不声称可以实时判断谁刚刚取关用户

## 以后只更新名单时怎么做

**只更新名单，不需要重新上传任何浏览器商店。**

1. 修改 `extension/data/blocklist.json`
2. 去重
3. 更新 `version`
4. 更新 `updated_at`
5. 更新 `review_note`
6. 跑名单测试
7. commit
8. push GitHub
9. 等 GitHub Pages 更新并验证远程 JSON

不要：

- 不提升扩展版本号
- 不重新生成 ZIP
- 不重新上传 Chrome
- 不重新上传 Edge
- 不重新上传 Firefox
- 不重新上传 Opera

只有插件代码、UI、权限、执行逻辑或远程名单数据源地址变化时，才重新发商店版本。
