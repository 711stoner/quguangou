## 名单更新规则
- 只更新黑名单 / 单向取关名单数据时，不升级插件代码版本，也不重新提交任何商店
- 修改唯一名单源 extension/data/blocklist.json
- 去重并更新名单 version、updated_at、review_note
- 测试后提交并 push GitHub
- GitHub Pages 更新后，四个平台已安装版本都会优先读取最新远程名单
- 远程读取失败时回退到缓存和安装包内置备用名单
- 只有代码、界面、权限、功能、运行逻辑或远程数据源地址变化时，才重新提交商店版本
