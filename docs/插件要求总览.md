# 取关狗插件要求总览

## 本地发布文件规则

- 本地只保留当前最新可上传版本，不保留旧 ZIP。
- 唯一发布目录位于移动硬盘：/Volumes/15055751248/vibe的脚本/04-发布包/取关狗/。Chrome、Edge、Firefox 三个平台的最新 ZIP、最新商店截图和上架资料都统一放在这里；不要放到桌面、下载或其他临时目录。
- 每次生成新版本后，先确认三个 ZIP 的版本号、名单版本和功能一致，再替换本地发布文件夹中的旧 ZIP。
- 旧版本 ZIP 在删除本地副本前，必须确保已经归档到 GitHub 仓库或 Git 历史中；仓库保留历史版本，本地不保留。
- 插件市场上传时，只从移动硬盘 /Volumes/15055751248/vibe的脚本/04-发布包/取关狗/ 选择文件。

## 商店素材规则

- 最新商店截图、Logo、上架说明与审核资料同样放在这个「取关狗」发布文件夹中。
- 新版素材替换旧版素材；旧素材如需留档，保存在仓库，不在本地发布文件夹重复保留。
- 商店截图使用 1280×800 或 640×400，JPEG 或 24-bit PNG，无透明通道。

## 名单更新规则

- 只更新黑名单数据时，不升级插件代码版本，也不重新提交插件市场。
- 更新 extension/data/blocklist.json，核查账号、去重、记录日期和总数后推送 GitHub。
- 只有插件代码、界面、权限、功能发生变化时，才升级插件版本并重新生成 Chrome / Edge / Firefox ZIP。
- 每批名单截图归档进仓库后，本地原始截图可删除。

## 浏览器商店版本记录规则

- 只记录真实上传到 Chrome / Edge / Firefox 商店后台的版本。
- 审核中的版本也记录，但必须标明真实审核状态。
- 本地测试版、临时版、错误版如果没有上传商店，一律不写。
- 单纯更新在线名单而没有重新上传扩展包，不新增插件版本记录。
- 每条至少记录：版本号、上传日期、平台、审核/上线状态、本次主要更新。
- 详细记录文件：docs/浏览器商店版本记录.md

## 附加账号工具与导流

- 固定账号工具卡：正常排版，不悬浮、不遮挡核心功能，可永久关闭。
- 固定卡关闭后仅隐藏该固定卡；拟人化冷却页小导流和全部完成页大导流仍保留。
- 商店描述必须明确这是可关闭、完全可选的附加账号工具入口，不影响核心功能。
- 不在取关狗内直接引导安装其他浏览器扩展。
