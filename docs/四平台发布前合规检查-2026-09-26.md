## 单一核心用途
面向 X 中文社区的账号管理辅助工具：展示社区黑名单与单向取关线索，并由用户主动发起、按分批节奏拉黑名单账号。

明确不是个人取关检测器，不扫描粉丝 / 关注历史，不声称能实时判断谁刚刚取关用户。

## 可选估值入口
- 首页不显示
- 20 个一批进入 30 分钟冷却时显示一张
- 全部处理完成时显示一张
- 不自动打开，不点击不影响核心功能
- 打开开发者自有网站 jiedanfadan.com/value-check
- 商店描述统一写“可选广告价值估算入口”，不写“插件内置估值算法”

## 四个平台
Chrome：保持单一用途、metadata 准确、关键词自然出现、不堆砌。
Edge：Single Purpose、权限理由、Privacy、Search terms 与实际一致，Search terms 不超过 7 个。
Firefox：遵守 No Surprises，在 listing 提前披露冷却 / 完成阶段的可选估值入口。
Opera：保持 One goal，自有网站链接相关且有明确作用，不让弹窗被大量推广链接占据。

## 名单推送规则
只更新名单时：
1. 修改 extension/data/blocklist.json
2. 去重并更新 version、updated_at、review_note
3. 跑测试
4. 提交并 push GitHub
5. 等 GitHub Pages 更新并验证远程 JSON
6. 不修改扩展版本号，不重新生成商店包，不重新上传 Chrome / Edge / Firefox / Opera
