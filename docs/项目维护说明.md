## 当前产品说明

取关狗是一个面向 X 互关冷启动场景的 Chrome 扩展项目。核心文案是：

> 把注意力，还给自己。

扩展说明：

- 用户登录自己的 X 账号。
- 用户先查看扩展内置名单。
- 用户主动点击后，扩展依次打开名单账号主页并尝试拉黑。
- 不读取 X 密码。
- 不上传用户账号数据。
- 不依赖远程服务器完成拉黑。
- 非 X Corp. 官方产品，与 X Corp. 无隶属或认可关系。

## 执行节奏与风险提示

- 每批最多尝试处理 20 个账号。
- 一批结束后进入 30 分钟冷却期。
- 冷却期结束后，需要用户手动再次点击继续。
- 设计目标是降低短时间连续操作的风险，但不能保证账号安全。
- X 官方规则禁止非 API 自动化操作；使用可能导致账号受限、暂停或永久停用。
- 页面文案要提醒用户自行阅读平台规则、自行判断风险。

## 名单原则

- 拉黑名单来自用户提供的相关证据截图。
- 名单不是自动爬虫采集的数据。
- 新增线索需要在 X 评论区提交，并尽量附截图证据。
- 被收录账号可以在评论区说明理由并提交补充材料，申请复核、更正或解除拉黑。
- 已经显示“已屏蔽”的账号也可以加入名单。

## 安装说明重点

官网应写清楚：

1. 下载 ZIP。
2. 双击解压。
3. 打开 Chrome 浏览器新标签页。
4. 复制 `chrome://extensions`，粘贴到浏览器最上方的地址栏，不要粘贴到搜索框。
5. 打开“开发者模式”。
6. 点击“加载已解压的扩展程序”。
7. 选择解压后的整个 `quguangou-chrome-v版本号` 文件夹，不要点里面的单个文件。

当前官网还需提示：

- Google Chrome 插件市场版本仍在上传中，请先手动下载 ZIP 使用。
- 如果是手动安装，名单更新后需要重新下载安装或重新加载新版文件夹。
- 如果以后从 Chrome 插件市场安装，名单更新通常随扩展自动更新，只需要再次打开扩展执行。

## 下次更新名单流程

1. 从用户截图中提取 X 用户名，格式统一为不带 `@` 的 `username`，展示时再加 `@`。
2. 检查是否重复。
3. 优先确认截图里账号可识别、能打开主页；已屏蔽账号也可以加入。
4. 粉丝/关注差距明显异常的账号可作为辅助判断，但不要仅凭比例收录。
5. 修改 `extension/data/blocklist.json`。
6. 更新名单版本号，例如 `2026.09.13.2`。
7. 运行格式检查、重复检查和扩展测试。
8. 如扩展包内容变化，更新 `manifest.json` / `package.json` 版本并重新打包 ZIP。
9. 更新官网下载链接和版本号。
10. 提交 Git commit、push，然后创建 GitHub Release。
