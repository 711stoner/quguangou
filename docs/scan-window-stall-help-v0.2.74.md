# 取关狗 v0.2.74：扫描窗口消失与进度停滞说明

日期：2026-11-03

## 修复内容
- 在进度条下方、操作按钮上方加入清晰的操作说明；把“重新打开扫描窗口（保留进度）”放在暂停按钮前面。
- 明确区分 **扫描窗口消失**、**超过 3 分钟账号数量未增加**、**HTTP 429 冷却中** 和 **用户手动暂停**；十种语言各有对应说明。
- 去掉以前在渲染末尾用固定文字覆盖具体状态的操作，窗口异常时不再继续显示“正在快速读取”。
- 保存真正新增账号的时间 `lastAccountProgressAt`，普通 UI 心跳/存储刷新不会把计时器清零。
- 后台只在轻量 `GET_PERSONAL_SCAN_HEALTH` 请求时核对扩展自有的 X 扫描窗口，不抓取新的 X 数据；侧栏每 5 秒更新一次帮助状态。
- 对窗口创建预留 30 秒缓冲，避免刚打开页面就误报。没有取消或清空扫描的自动操作，旧断点保护仍在。
