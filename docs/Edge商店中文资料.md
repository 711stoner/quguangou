# 取关狗 Edge 商店中文资料

版本：v0.2.25

## 商店标题
取关狗｜X（Twitter）黑名单、单向取关与分批拉黑

## 简短说明
X 中文社区黑名单与单向取关线索工具：查看社区名单，核对账号后分批拉黑，并采用拟人化冷却；不是个人取关检测器。

## 详细描述
取关狗是一款面向 X（原 Twitter）中文社区的账号管理辅助工具。它不是个人取关检测器，不会扫描你的粉丝列表或关注历史，也不会自动判断谁刚刚取关了你。

主要功能：
- 查看社区黑名单与单向取关线索
- 自动获取最新在线名单
- 每批最多处理 20 个账号
- 每批完成后拟人化冷却 30 分钟，冷却结束后手动继续
- 自动跳过已经拉黑的账号
- 停用、注销、404 或无法访问的账号记录原因后继续
- 在线名单不可用时使用缓存或内置备用名单
- 所有拉黑操作均由用户主动发起
- 任务数据仅保存在本地

附带入口：
- 冷却期间显示一张可选 X 推文广告价值估算入口
- 全部处理完成时显示一张完成场景入口
- 首页不显示估值入口
- 不点击不会影响核心名单处理功能
