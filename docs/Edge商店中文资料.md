# 取关狗 Edge 商店中文资料

版本：v0.2.16  
默认语言：中文（简体）

## 商店标题

取关狗｜X（Twitter）取关名单与批量拉黑工具

## 简短说明

不是取关检测器。整理 X 中文社区公开曝光、互关帖线索和用户投稿形成的取关名单，确认后可一键依次拉黑。

## 详细描述

取关狗是一款面向 X（原 Twitter）中文社区的取关线索名单工具。

它不是个人取关检测器，不会扫描你的粉丝列表、关注历史，也不会自动判断“谁刚刚取关了你”。

取关狗整理 X 中文社区中的公开曝光、互关帖线索以及用户提交的相关证据，经人工整理后形成社区取关线索名单。安装扩展后，你可以查看当前名单，并在主动确认后，依次处理名单中的相关 X 账号。

主要功能：

- 查看社区整理的 X 取关线索名单
- 自动获取最新社区名单
- 用户主动确认后依次处理名单中的账号
- 在线名单暂时不可用时使用缓存或内置备用名单
- 所有拉黑操作均由用户主动发起
## 隐私与数据

取关狗不会读取、请求或保存你的 X 密码，不会读取私信，也不会扫描你的粉丝或关注历史。

扩展仅在实现核心功能所需要的范围内访问 x.com 页面，并从取关狗官方网站读取公开的社区名单数据。

取关狗不是 X Corp. 的官方产品，与 X Corp. 不存在隶属、认可或授权关系。
