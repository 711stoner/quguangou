隐私政策

扩展处理哪些信息

取关狗仅在用户主动执行名单处理时访问 x.com 用户页面，用于识别页面菜单、执行拉黑并判断结果。扩展不会读取、请求或保存 X 密码、身份验证 Cookie、私信或发帖内容，也不会扫描用户的粉丝或关注历史。

本地存储

扩展使用浏览器本地存储保存任务进度、目标账号和执行结果，以便弹窗关闭后继续显示进度。相关信息仅保存在用户自己的设备中。

数据传输

扩展启动时会从 711stoner.github.io 下载公开的社区名单 JSON，以获取最新名单。该请求不会包含用户的 X 密码、粉丝/关注历史、任务记录或 X 账号信息；在线读取失败时，扩展会使用上一次成功缓存或随扩展打包的本地备用名单。GitHub Pages 作为托管服务可能按照其常规日志规则处理 IP 地址、User-Agent 等标准网络请求信息。

扩展没有开发者分析 SDK 或第三方广告 SDK，不会把用户的任务记录、拉黑结果、浏览数据或 X 账号信息发送给开发者。

权限用途

  • storage：保存本地任务进度和结果。
  • scripting：在 X 用户页面识别并操作拉黑相关控件。
  • https://x.com/*：打开名单中的 X 用户页面并完成用户主动发起的操作。
  • https://711stoner.github.io/*：仅读取公开的最新社区名单 JSON。

名单线索

名单线索来自 X 中文社区公开信息和用户投稿，并由维护者人工整理。提交者应只提供核对所需的信息，不应提交密码、Cookie、访问令牌、联系方式、私信内容或无关人员信息。被收录账号可以提交补充材料申请复核、更正或移除。

用户控制

扩展不会自动启动任务。用户可以先查看名单，再主动决定是否执行，并可停止尚未完成的任务。

联系我们

反馈、名单线索、申诉或隐私问题请前往 取关狗支持页。

可选估值入口

扩展仅在批次冷却和全部处理完成时展示一个可选的 X 推文广告价值估算入口。只有用户主动点击后，浏览器才会打开 jiedanfadan.com/value-check。扩展不会把用户的 X 账号信息、名单处理结果、粉丝/关注历史或任务记录自动传送到该页面；链接仅包含固定来源标记参数。
