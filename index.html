INSTALL

安装取关狗，照着这 6 步操作

Chrome 不允许网页直接安装商店外的扩展，所以第一次需要手动加载。整个过程只需要选择一个文件夹，不需要打开或修改里面的任何文件。

01

下载扩展

点击页面上方“下载 Chrome 扩展 v0.2.12”。下载完成后，在 Chrome 右上角的下载记录中找到压缩包。

02

解压 ZIP

双击下载的 quguangou-chrome-v0.2.12.zip。电脑会生成一个同名文件夹，这个完整文件夹就是稍后要选择的扩展。

03

在 Chrome 浏览器打开扩展管理页

先打开 Chrome 浏览器的新标签页。复制 chrome://extensions，粘贴到浏览器窗口最上方平时输入网址的地址栏里，然后按键盘上的回车键。不要粘贴到百度、Google 或其他搜索框中。

04

开启开发者模式

在扩展管理页右上角找到“开发者模式”，打开它。页面上方会出现“加载已解压的扩展程序”按钮。

05

选择整个文件夹

点击“加载已解压的扩展程序”，选择刚才解压出的 quguangou-chrome-v0.2.12 整个文件夹，再点击“选择”或“打开”。

06

确认安装成功

扩展管理页出现“取关狗”卡片即安装成功。点击 Chrome 工具栏的拼图图标，可将“取关狗”固定到工具栏。

注意：不要点击文件夹里的 manifest.json、popup.html、background.js 等文件。Chrome 要求选择的是包含这些文件的整个文件夹。 重新下载 v0.2.12

ORIGIN

为什么会有取关狗

新人账号做冷启动时，“互相关注”是一种常见的连接方式。双方基于约定彼此关注，建立最初的互动和信任；但也有人在获得关注后单方面取消关注，并且不作任何说明。这种行为会增加新人维护关系的成本，也会损害互关双方的信任。

取关狗因此诞生。我们收集由用户主动提交、并附有相关截图证据的单方面取关记录，在审核和整理后形成名单，提供给有需要的用户查看。用户可以根据自己的判断，一次点击依次拉黑名单中的账号，减少重复核对和手动处理的时间。

名单不是对任何账号作违法或恶意定性，也不代替用户作决定。被收录账号如认为信息有误、存在合理原因或已经解决争议，可以通过网站留言公开说明，我们会根据反馈和补充证据进行复核、更正或移除。

TRANSPARENCY

名单不是黑箱

名单的维护应当可解释、可复核，也允许被纠正。

有据

用户提交截图证据

名单线索来自用户上传，提交时需要说明账号、时间和经过，并提供能够支持记录的截图。

审核

不因单方描述直接收录

提交内容需要经过整理和复核。无法识别账号、证据不完整或与互关无关的线索不应进入名单。

纠错

允许公开反馈与申诉

被收录账号可以说明原因并提供补充材料。确认有误、争议已解决或不再符合标准时，应更正或移除。

重要说明：拉黑名单均来自用户提供的相关证据截图，并经过人工整理，不是自动爬虫采集的数据。你可以在评论区提交新的线索；如果你的账号被收录，也可以说明理由并提交补充材料，申请复核、更正或解除拉黑。 前往评论区
