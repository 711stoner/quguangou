INSTALL

安装取关狗，照着这 6 步操作

Chrome 不允许网页直接安装商店外的扩展，所以第一次需要手动加载。整个过程只需要选择一个文件夹，不需要打开或修改里面的任何文件。

01

下载扩展

点击页面上方“下载 Chrome 扩展 v0.2.13”。下载完成后，在 Chrome 右上角的下载记录中找到压缩包。

02

解压 ZIP

双击下载的 quguangou-chrome-v0.2.13.zip。电脑会生成一个同名文件夹，这个完整文件夹就是稍后要选择的扩展。

03

在 Chrome 浏览器打开扩展管理页

先打开 Chrome 浏览器的新标签页。复制 chrome://extensions，粘贴到浏览器窗口最上方平时输入网址的地址栏里，然后按键盘上的回车键。不要粘贴到百度、Google 或其他搜索框中。

04

开启开发者模式

在扩展管理页右上角找到“开发者模式”，打开它。页面上方会出现“加载已解压的扩展程序”按钮。

05

选择整个文件夹

点击“加载已解压的扩展程序”，选择刚才解压出的 quguangou-chrome-v0.2.12 整个文件夹，再点击“选择”或“打开”。

06

确认安装成功

扩展管理页出现“取关狗”卡片即安装成功。点击 Chrome 工具栏的拼图图标，可将“取关狗”固定到工具栏。

注意：不要点击文件夹里的 manifest.json、popup.html、background.js 等文件。Chrome 要求选择的是包含这些文件的整个文件夹。 重新下载 v0.2.13

ORIGIN

为什么会有取关狗

取关狗解决的不是“谁刚刚取关了我”。我们不读取你的关注历史，也不做个人取关检测。项目关注的是 X 中文社区里已经公开出现、或由社区用户提交的互关后取关线索。

名单主要来自三类来源：第一，X 中文社区公开帖子中对“互关后取关”的曝光记录；第二，在互关帖下主动留言、但主页关注与粉丝比例明显异常的账号线索，例如关注约 1000 人、粉丝约 3000 人——这类比例只作为待核对线索，不单独认定取关行为；第三，用户通过私信或公开入口投稿“互关后又取关我”的账号，并提供截图、时间线等材料。线索经人工整理和复核后才进入名单。

名单来自整个 X 中文社区，并不只包含你当前关注的人。安装扩展后，你可以先查看名单，再根据自己的判断，一键依次拉黑其中账号，减少逐个搜索和处理的时间。

名单不是对任何账号作违法或恶意定性，也不代替用户作决定。被收录账号如认为信息有误、存在合理原因或已经解决争议，可以通过网站留言公开说明，我们会根据反馈和补充证据进行复核、更正或移除。

TRANSPARENCY

公开

社区公开曝光

收集 X 中文社区公开帖子中“互关后取关”等曝光记录，并保留可核对的账号、帖子或截图信息。

线索

互关帖异常比例

互关帖下主动留言、但主页关注与粉丝比例明显异常的账号可作为待核对线索，例如关注约 1000、粉丝约 3000；不单凭比例认定存在取关行为。

投稿
